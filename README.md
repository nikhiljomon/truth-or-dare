# Truth or Dare | Party Edition

A static, multi-file Truth or Dare party game. Open `index.html` directly in a modern browser or publish the folder on GitHub Pages; scripts use classic deferred loading so local `file://` use does not require a web server.

## Project files

- `index.html` contains the game markup.
- `css/` contains the theme variables, base rules, components, and responsive styles.
- `js/` contains prompt data, shared state, UI helpers, game logic, preferences, and startup wiring.
- `assets/` is reserved for local media; the original page has no embedded or local media files to move.

The original Google Fonts stylesheet link is retained; the current CSS font variables continue to use Arial with system fallbacks.
